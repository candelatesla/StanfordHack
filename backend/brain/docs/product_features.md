# Product Features

Core analytics (all tiers): dashboards, scheduled reports, 50+ native connectors and a SQL workspace. Growth adds SAML SSO and REST API access. Enterprise adds a dedicated Customer Success Manager, HIPAA BAA support, EU data residency, audit logs and custom roles.

Nimbus does not currently offer an on-premise deployment; it is a multi-tenant SaaS platform with single-tenant options on the roadmap.

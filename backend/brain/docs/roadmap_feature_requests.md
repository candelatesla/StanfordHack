# Roadmap and Feature Requests

Reps must not commit to roadmap features or dates in a contract or on a call. Share only what is on the public roadmap, and describe it as planned, not guaranteed.

Publicly planned items include single-tenant deployment (planned for the second half of next year) and additional data residency regions in APAC and Canada. On-premise deployment is not planned.

Feature requests should be logged in the CRM with the customer's use case and deal size so Product can prioritise them. The customer can meet a product manager on request for strategic Enterprise deals.

# AI Features

Nimbus Assist lets business users ask questions in plain English and get governed answers, built only on the customer's approved metrics. It is included on Growth and Enterprise at no extra cost.

Customer data is never used to train AI models, and prompts are not retained by model providers. AI features can be switched off for the whole workspace by an admin.

Nimbus Assist cites the metric and dashboard behind every answer so users can verify it.

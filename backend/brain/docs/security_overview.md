# Security Overview

Nimbus is SOC 2 Type II certified (report available under NDA) and is audited annually. Customer data is encrypted at rest with AES-256 and in transit with TLS 1.2 or higher. Nimbus runs on AWS with production access restricted to on-call engineers through SSO with hardware-key MFA, and every access is logged.

Nimbus completes an independent penetration test every year and runs a public bug bounty program. A summary of the latest pen test is available under NDA. Role-based access control, row-level security and audit logs are available; audit logs are Enterprise only.

Nimbus will complete a customer's security questionnaire, and has pre-filled SIG Lite and CAIQ questionnaires ready to send. The current list of sub-processors is published on the trust center, and customers are notified of a security incident affecting their data within 72 hours.
